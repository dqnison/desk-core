# `desk.yml` — настройки движка

Необязательный файл в корне `DESK_HOME`. Отдельно от правил: вход (`tier: import`)
грузится в каждую сессию целиком и не должен везти данные движка.

```yaml
portable: ['desk.md', 'process/**']   # переносимый слой — без имён мест
entry: '~/.claude/CLAUDE.md'          # вход ассистента: desk lint сверит @-импорты с ярусом import
triggers: {…}                         # общие триггеры, см. «when:»
require_tier: ['process/*.md']        # desk lint: у этих файлов обязателен tier
interfaces: {local: 'как поднять', …} # desk lint: словарь имён файлов в contexts/ —
                                      # в projects/<репо>/ только они, один ярус на всех слоях
```

`contexts/<место>/desk.yml` — триггеры места под теми же именами: они дополняют корневые,
пока место активно. Переносимое правило пишет `when: [tracker]`, а какой CLI или API
считается трекером, говорит место; где место триггер не определило, правило молчит.
Там же ветки места — `branches: {integration, production, repos: {<репо>: …}}`: по ним
на старте видно, на базе ли чекаут, и какой командой его привести.
